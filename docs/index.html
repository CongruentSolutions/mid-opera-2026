Segment 2 · 5–10 min

The world of Bifrost

The architecture everything this half sits on.

CORE keeps the financial truth. Bifrost is the only door into it. AI agents work through that door, under rules.

The four pieces, in one line each

PieceWhat it isWhat it does not do
COREThe recordkeeping system: plans, payroll, accounts, distributions, loans.It is not reachable except through Bifrost.
BifrostThe integration hub and the only door into CORE. It holds authorization, approvals, retry safety, events and audit, and speaks REST, MCP and A2A.It does not decide on a person's behalf.
AthenaThe front end for people and agents. Agents prepare and explain; a human approves.It never touches CORE directly.
RDX In designA neutral exchange for the retirement industry. A payroll provider or TPA connects once and reaches every recordkeeper. CORE is one participant, reached through Bifrost.It does not judge the meaning of data, and it is not built on CORE's stack. Today it is a design, with no code yet.

Why the shape matters

Authority stays in the middle.Agents are fast and can be wrong. Athena proposes, a human decides, Bifrost verifies and records, and CORE applies the change.
One door, one set of rules.Any agent, ours or a partner's such as Camunda, uses the same door and the same rules.
RDX is separate on purpose.If competing recordkeepers are to trust it, it cannot be owned by one of them.

The trust layer around it, CIATA and AGRUF, is a draft framework from the AI Reboot. See Trust.

Segment 5 · 30–40 min

Inside a withdrawal

Prototype 3, presented as architecture. Multilingual: English, French and Spanish.

The third prototype shows what happens when several agents and a process engine work one CORE task together.

A withdrawal arrives as a document, in English, French or Spanish. It has to be read in its own language, checked against plan facts, consented to, submitted and approved by a person, and every step must be auditable.

What the audience should take from it

Each party has one job.Camunda runs the process, Athena prepares evidence, Bifrost governs and records, CORE decides through a person.
Agents never hold final authority.Athena stops at the evidence handoff. Submission needs accepted human authority, and a person in CORE gives the decision.
A partner's agent can use the same door.Camunda uses Bifrost's agent endpoints (MCP and A2A), and a partner's agent would use the same ones under the same rules.
It follows CIATA.Roles, scope, human checkpoints and a replayable log are designed into the flow. CIATA is a draft framework.

Draft framework · AI Reboot

Trust, built in

Two layers of governance: one for agents, one for people.

CIATA

Governs agents

  • Every agent has an identity, a scope and a responsible owner.
  • Autonomy is graded from level 0 to level 4.
  • People stay in the loop where judgment, money or fiduciary duty is involved.
  • Every action, reason and human decision is logged and can be replayed.

AGRUF

Governs human use of AI

  • A registry of approved AI tools, reviewed for security and privacy.
  • Access by role, with clear rules on which data may go into which tool.
  • A signed responsible-use declaration for every employee using AI at work.
  • AI output is checked before anyone relies on it, and incidents are reported.
Segment 6 · 40–50 min

Your questions

Ten minutes. Bring anything about the architecture, the prototypes, or how your team can use them.

Can an agent move money on its own?

No, not in any flow we have built. Agents prepare and explain. A person approves, Bifrost verifies the person, and CORE applies the change.

How do we know what an agent did?

Bifrost records the actions and approvals. CIATA requires every agent to have an identity, scope and replayable log.

What stops an agent from seeing data it should not?

Agents reach CORE only through Bifrost, with authorization checked at Bifrost. AGRUF sets the rules for people using AI tools.

Can a partner's agent connect?

Yes, through the same Bifrost endpoints (MCP and A2A) under the same rules.

What is RDX, and how is it different from Bifrost?

Bifrost is CORE's door. RDX is a neutral exchange for the industry, and CORE is one participant behind it.

What does the Spark result mean?

Spark was our internal target to build demos for conference season. Payroll was the accepted scope and it is done; the participant and orchestration prototypes extend it.

Why are three Toledo key results rated 0%?

The orchestrator has a working skeleton. The Requirement Engine and the coding agents have designs and no code yet. Finishing Toledo, Cordoba and Dr Watson is the immediate focus.

Why no commits since August?

The effort moved to the Spark prototypes. Toledo, Cordoba and Dr Watson are the immediate focus next.
